 Python Countdown Timer
A simple Python countdown timer that converts seconds into hours, minutes, and seconds and plays an alarm sound when the timer finishes.
Features
Countdown display in HH:MM:SS format
Input validation for user safety
Alarm sound when time ends (Windows)
Simple and beginner-friendly Python project
Technologies Used
Python
time module
winsound module (Windows only)
How to Run
Clone the repository:
git clone <your-repo-link> 
Navigate to the project folder:
cd python-countdown-timer 
Run the program:
python countdown_timer.py 
Enter time in seconds when prompted.
Example Output
ENTER THE TIME IN SECONDS: 5 00:00:05 00:00:04 00:00:03 00:00:02 00:00:01 TIMES UP!!!!!!!! 
 Note
winsound works only on Windows.
Make sure your system sound is enabled.
